🛠️ Qiaomu Home
一句话

面向 Obsidian 的个人启动工作台，把今日任务、最近笔记、常用网址、阅读入口和可选插件卡片集中到一个可定制主页。

链接

https://github.com/joeseesun/qiaomu-home；官方插件页：https://community.obsidian.md/plugins/qiaomu-home ↗

怎么玩

打开 Obsidian，进入“设置 → 第三方插件 → 浏览”，搜索 Qiaomu Home，确认作者为向阳乔木后安装并启用。打开新标签页，点右侧齿轮进入布置模式，先保留默认页签，再添加“今日代办”“最近笔记”“快捷入口”和“继续阅读”等卡片；在“今日代办”里输入事项并回车，检查它是否写入今日日记。想手动安装时，从 GitHub Release 下载同一版本的 main.js、manifest.json、styles.css，放入库内 .obsidian/plugins/qiaomu-home/，升级时保留 data.json 和缓存。第一次建议只接入本地笔记和网址，确认布局、搜索和快捷入口都符合自己的工作流后，再添加外部插件联动。

为什么值得关注

它不只是一个漂亮的新标签页，而是把“打开 Obsidian 后下一步做什么”固定成一个低摩擦入口。README 明确说明任务和捕捉内容仍留在本地 Markdown，基础功能无需注册，搜索本地完成，也不会自动安装或启用其他插件；模块库还覆盖日记、任务、阅读、搜索和 GitHub 待办。对已经用 Obsidian 管理项目、读书和日报的人，这种本地优先的工作台比又增加一个云端面板更容易长期使用。

应用场景
  • 把今日日记、项目笔记和常用站点放在同一启动页，减少每天找文件的时间。
  • 配合阅读、RSS 或 Agent 类 Obsidian 插件，把收集、处理和回顾串成连续流程。

🛠️ Mole 1.15
一句话

面向 macOS 的开源清理、软件管理、卸载、磁盘分析和系统状态监控工具，同时提供原生 Mac 应用。

链接

https://mole.fit/zh/#tested-apps；GitHub：https://github.com/tw93/Mole ↗

怎么玩

如果使用 macOS，先阅读官网的安装说明和测试软件清单，再从 Homebrew 安装命令行版：brew install tw93/tap/mole。第一次不要直接删除文件，先分别运行 mo clean --dry-run、mo uninstall --dry-run、mo analyze 和 mo status，逐项查看将要处理的路径、软件残留、磁盘占用和系统状态；对模型权重、虚拟环境、node_modules、浏览器缓存等目录先建立白名单并备份。确认预览结果后，再只执行一个小范围清理，随后检查开发工具、Agent 沙箱、外接磁盘和系统服务是否正常。需要图形界面或菜单栏指标时，再评估官网提供的 Mole for Mac，不要把商业 App 与免费 CLI 混为一谈。

为什么值得关注

Mole 1.15 的外部页面显示，它已亲手测试和核查 709 款 Mac 软件，并把清理、卸载、优化、磁盘分析和状态查看放到一个入口；命令行版还保留开源和可审查的操作路径。对经常下载模型、构建前端项目和运行多套 Agent 的开发者，最大的实际价值是先看报告、再决定删除什么，而不是依赖一键“加速”宣传。它也提醒我们，系统维护工具越强，dry-run、保护名单和备份越重要。

应用场景
  • 定期定位并清理 Mac 上的构建产物、安装包、缓存和已卸载应用残留。
  • 分析开发机或模型盘的空间构成，并在清理前保留可回读的状态证据。

解读

解读
