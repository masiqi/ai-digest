🛠️ yovoice
一句话

开源桌面语音工作台，在 macOS/Windows 本地使用多种 TTS 模型制作旁白、角色配音与参考音色克隆。

链接

https://github.com/leemysw/yovoice ↗

怎么玩

打开仓库 Releases，按系统选择 macOS Apple Silicon 的 DMG 或 Windows x64 安装包；首次打开进入 Settings，先下载容量适合本机的模型。新建 Speech generation 或 Story dubbing 项目，输入一段中文短文，选择预置声音试听，再导入自己拥有使用权的参考音频，调节角色与情绪，点击 Generate speech 预览并导出音频。需要让编码 Agent 调用时，再阅读仓库 docs/cli.md 与 skills/yovoice 的安装说明；先用一小段文本验证发音、速度和显存占用，再制作长稿。

为什么值得关注

项目把 IndexTTS、VoxCPM、Qwen3-TTS、Kokoro 等不同大小的本地模型接进统一界面，同时提供字幕导入、片段预览和 Agent Skill，适合避免逐字付费的反复修改。模型文件可能达到数 GB，具体模型许可与商用条件各不相同；尤其不要把他人的声音当作可随意克隆的素材。

应用场景
  • 把读书笔记或产品讲解做成个人配音，在本机反复修订语气。
  • 用获得授权的声音样本，为教学视频制作多角色中文旁白。

怎么玩
