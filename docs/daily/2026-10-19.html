🛠️ huashu-motion
一句话

把产品信息交给编码 Agent，由 Skill 生成可编辑的代码动画发布片、配乐与导出文件。

链接

https://github.com/alchaincyf/huashu-motion ↗

怎么玩

先确认本机具备 Node 22 以上、Chrome 或 Chromium 与 FFmpeg；在 Claude Code、Codex 等支持 Agent Skills 的环境运行 `npx skills add alchaincyf/huashu-motion`。先让 Agent 安装后运行仓库 demo，再给它自己的产品介绍或官网，明确要做“30 秒发布片”，选择它提出的方向。预览时在编辑器按 C、点画面局部并写修改意见；完成后让它运行检查、质检和渲染，再导出 MP4。仓库说明目前主要在 macOS 实测，别把样片质量当成所有模型的保底效果。

为什么值得关注

它不是把一句话交给黑箱视频模型，而是让 Agent 编写可修改的 HTML 动画、在本机浏览器逐帧渲染；仓库把节奏单、镜头语言、谱面配乐、定位到画面元素的评论反馈及交付前抽帧检查放在同一条工作流中。特别适合需要反复修改文案和数字的产品演示，但需要自己验收最终画面与声音。

应用场景
  • 新产品上线时先做一支可逐句修改的功能发布片，再剪成社媒竖屏版。
  • 把季度数据和转化漏斗改成有节奏的讲解动画，而不是静态截图。

一句话

链接

https://github.com/obsidianmd/pele ↗

https://pele.run/playground ↗

怎么玩

不用先安装也能到官网 playground，把 `flowchart TD A[开始] --> B[验收]` 贴进去，观察生成的 SVG；如果要嵌入自己的网页，执行 `npm install pele`，按照仓库 README 导入 `render`，将 Mermaid 文本交给 `render` 并把返回的 SVG 插进页面。想让图跟随侧栏宽度和主题变化，改用面向浏览器元素的 `mount()`，再用 CSS 变量设置前景和背景色。对不可信图表输入，先读项目安全文档再开放给用户编辑。

为什么值得关注

项目提供同步、零运行时依赖的渲染接口，支持 Mermaid 12.1.0 内置图表类型，并把主题颜色与字体交给 CSS 变量；官网还给出了性能和体积对比，但那是项目方数据，部署前应在自己的图型与浏览器里测量。对于 Agent 自动生成的图，安全边界和容器自适应比单纯“能出图”更关键。

应用场景
  • 在 Obsidian 或知识库侧栏显示 Agent 绘制的系统调用链。
  • 把项目架构图嵌入产品文档，并跟随暗色主题变换配色。

🛠️ grokbot-local-agent
一句话

让 Grok Bot 将耗时工作派给同机 Pi Agent，结束时通过 Webhook 唤醒 Bot 回来验收。

链接

https://github.com/robbin/grokbot-local-agent ↗

怎么玩

先读仓库的 `docs/setup-guide.md` 与 `skills/pi-agent/SKILL.md`，准备 Node 22、Pi、可工作的模型登录和 Grok Bot 环境；将仓库里的 `bin/pi-task` 与配套 `.mjs` 放到同一目录。先用一条不涉及私密数据的小任务验证同步入口，再配置 Bot 的 Webhook 通知例行任务；派活时带 `--owner`，任务结束后看 `~/.pi/tasks/<任务ID>/` 中状态、事件和结果，再让 Bot 复核后 `ack`。Webhook 丢失时用 `pi-task pending` 补查，不要把通知到达当成任务成功。

为什么值得关注

这个项目正面处理“云端调度器派完活就休眠”的断链：任务落盘、按 owner 区分、完成事件通知和待汇报补偿都属于可恢复性设计。作者也明确提醒同机脚本不是严格隔离的沙箱；给它文件读写或网络权限前，必须检查自己的信任边界。其价值是工程模式而不是保证某个订阅一定省钱。

应用场景
  • 手机给 Bot 派一项代码改动，结束后回读本地任务产物再决定是否合并。
  • 把文档批处理交给较便宜的本地 Agent，同时保留失败补查与人工验收。
