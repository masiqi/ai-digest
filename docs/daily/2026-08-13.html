一句话

链接

https://api-docs.deepseek.com/guides/function_calling ↗

怎么玩

先在 DeepSeek API 控制台申请 Key，把 `DEEPSEEK_API_KEY` 写入环境变量；如果已有 OpenAI SDK，只需把 base_url 改成 `https://api.deepseek.com`，model 改为 `deepseek-v4-pro`，就可以先跑一条普通对话，再打开 thinking 和 tool calls。需要兼容 Anthropic 工作流时，把入口切到 `https://api.deepseek.com/anthropic`，用同一组业务提示词分别测试代码修复、网页资料整理和函数调用。建议同时记录首 token 延迟、总耗时、输入缓存命中率和工具失败率，不要只看一次生成结果。

应用场景
  • 替换现有 OpenAI 兼容后端，做长文档分析和代码 Agent。
  • 用 Anthropic 兼容入口接入已有工具调用或多轮工作流。
