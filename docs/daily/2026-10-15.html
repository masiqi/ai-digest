🛠️ VoiceMem：给实时语音 Agent 分左右脑的记忆层
一句话

从语音中抽取事实与情绪/偏好记忆，并在下一轮对话中检索相关内容的开源 Python 项目。

链接

https://github.com/xzf-thu/VoiceMem ↗

https://xzf-thu.github.io/VoiceMem/ ↗

怎么玩

先打开项目主页确认机器环境和模型下载体量，在隔离 Python 环境安装 voicemem；按主页 Quick Start 创建 VoiceMem 实例，配置自己的模型服务密钥，执行 warmup 后用一段已获授权的短语音调用 ingest，再用 search 提问验证事实记忆和偏好记忆是否分开命中。需要实时链路时参考 stream 的 32 毫秒分块示例，比较“说话中检索”与说完再检索的延迟；公开仓库还提供 web/run.py 演示，但要先下载模型并单独配置所需密钥。不要把真实用户敏感音频直接丢给公开 Demo。

为什么值得关注

它不是单纯把语音转文字后塞进向量库，而是把人物与知识的“左脑”和情绪、偏好的“右脑”分开组织，且尝试在语音输入尚未结束时做记忆检索。主页的性能数字属于项目方自报，适合先用自己的对话数据测召回、串人及隐私边界，再决定是否用于生产语音助手。

应用场景
  • 家庭语音助理记住饮食限制、称呼及个性化偏好。
  • 数字人或客服在长对话中减少重复询问，并验证身份隔离。

怎么玩

Apple Silicon Mac 用户先到 Releases 下载 macOS DMG，拖进应用程序后打开；首次选择一个不含私人密钥的小文件夹，让程序下载一次模型并完成索引，再用自然语言描述“那段提到睡眠的录音”或“有斑马的视频”，检查是否定位到相应时间点。可再选一个 PDF 测试页码与关键字高亮。测试代码检索时在设置中单独启用对应仓库，用 code: 前缀查询函数职责；索引前先检查目录权限与模型所需磁盘空间，避免把整个家庭目录无差别加入。

应用场景
