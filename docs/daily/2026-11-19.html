🛠️ ABFS：Android 巨型仓库按需挂载，别把缓存命中当首次构建
一句话

Google 开源 Another Build File Service，通过内容寻址文件系统和共享构建缓存缩短 Android 检出与重复构建等待。

怎么玩

适合维护 AOSP 分支、多人共用 CI 缓存的团队。先读仓库安装与架构，准备隔离 Linux 开发机、Git、libcap 和 Go 工具链；审过 Makefile 的 setcap 权限后再 make。完整挂载还需 CASFS 内核模块，远端 CAS/缓存服务由管理员准备。先在同一分支比较冷缓存、热缓存及改一个文件后的构建，不要直接迁生产构建池。 边界与费用：官方在 64 vCPU、256GB GCE、客户端与服务端同 VPC 的三次均值中，检出由 36分19秒到冷缓存挂载7.4秒；这是先得到目录、内容按需读取，不是8秒下载全部源码。构建禁缓存反而由1时20分35秒变1时39分11秒，远端缓存齐全才降到2分11秒。依赖强网络、管理员和额外存储，非确定性构建会损失命中率；Apache-2.0。只核文档，未安装。
