🛠️ huashu-art-motion：让 coding agent 把艺术风格写成会动的画
一句话

一个开源艺术动画 skill，把 35 种艺术风格、9 种解说语法和参数化片段组织成可复用的代码创作流程，适合用 Claude 等 coding agent 做风格化短片、白板解释和口播动画。

链接

https://github.com/alchaincyf/huashu-art-motion ↗

怎么玩

先准备 Node.js、uv、ffmpeg 和 Playwright Chromium，在终端执行 `npx skills add alchaincyf/huashu-art-motion`；第一次运行按 README 执行 `uv run --with playwright playwright install chromium`。随后让 coding agent 读取 skill，先从仓库里的示范场景选一种风格，再把主题、角色、旁白和镜头节奏替换成自己的内容，运行脚本生成帧或动画。白板、Vox、讲解员等语法要先看对应参考代码；第九种讲解员语法需要自备角色素材，完整口播示例是代码快照，不要误认为下载后即可一键渲染。

为什么值得关注

它的价值不只是“换滤镜”，而是把画面风格、镜头运动、角色动作和口播结构拆成可重复的工程资产。README 同时给出样片、风格配方和许可证边界，适合拿来研究如何把一次性提示词沉淀成 agent skill；但仓库目前规模仍小，真实项目应先跑通一个短片，再评估素材和渲染成本。

应用场景
  • 把课程、科普或产品解说稿自动拆成带动作的白板/讲解员短视频。
  • 为 coding agent 增加一个艺术阶段，用同一套镜头语法快速试验不同视觉方向。

链接

https://github.com/vista8/qiaomu-ui-learn ↗

怎么玩

先打开仓库 README，按当前说明把插件安装进 Obsidian，再在设置里启用 qiaomu-ui-learn。第一次不要急着复制 Prompt，可以先浏览设计图库，挑一个组件或页面，记录布局、间距、字体、颜色和交互特点；接着用组件词典和风格图鉴把“好看”改写成可执行描述，完成审美测验后，再复制 Prompt 到自己的 coding agent，让它生成一个小页面。建议每次只改一个变量，并把结果截图与原参考并排对照，逐渐建立个人风格词表；插件上架状态以仓库和 Obsidian 当前页面为准。

为什么值得关注

应用场景
  • 为产品原型、个人网站和移动端页面建立可复用的视觉参考库。
  • 训练非设计背景开发者把模糊审美转成布局、组件和风格约束。
