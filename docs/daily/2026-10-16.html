🛠️ Handwired：把普通 JavaScript 逻辑手工编译成可微网络
一句话

开源实验项目，用手写权重将条件、循环等程序结构变成矩阵运算和激活函数，不靠训练获取程序行为。

链接

https://github.com/chenglou/handwired ↗

https://chenglou.me/handwired/ ↗

怎么玩

先打开在线演示，观察同一段简单条件判断在普通 JavaScript 与矩阵运算形式中的输出是否一致；想在本机改代码，则按仓库 README 克隆项目、执行 bun install 与 bun start，随后从 docs、src 和 template 入手，把一个整数比较或小规模搜索例子改成自己的输入。记录正确性、执行耗时和资源消耗，尤其别直接假设 WebGPU 版本一定比原始 JS 快；这是研究性原型，不是把任意代码一键变成高性能神经网络的成熟编译器。

为什么值得关注

作者明确展示了无需训练而保持可微的路径：用矩阵乘法和 ReLU 表达离散程序逻辑，未来或许可以连接固定规则程序与可训练模型；仓库还提到 JSON 搜索演示。它的价值在于提供可审查的技术实验，而非已经证明可以替代通用编译器或大模型。

应用场景
  • 研究如何把确定性业务规则与可学习模块连接，同时保留单元测试。
  • 给 WebGPU、矩阵计算和程序合成课程制作可视化实验。
