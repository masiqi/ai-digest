🛠️ dimensional-drawing：把 UI 组件画成工程尺寸图
一句话

给 Agent 一个组件源码、Storybook、网页或截图，让它输出标有间距、圆角和层级的单页技术图，还可追加短动画。

链接

https://github.com/enesozturk/dimensional-drawing ↗

怎么玩

打开仓库，查看 skills/dimensional-drawing/SKILL.md 与 examples；在支持 Skill 的编程 Agent 中加载该目录，指定自己的 Card 或 Dialog 组件源码，要求生成 dimensional drawing。先核对图上的 padding、gap、圆角变量与实际 CSS 是否一致；未知尺寸应保留 TBD，不能让模型编造。需要演示动画时再加载 dimensional-drawing-motion，按仓库 headless 说明用 Node 与 ffmpeg 渲染 MP4，或在支持 Motion 的 Claude 环境导出。

为什么值得关注

它并非让模型随意生成漂亮设计图，而是刻意剥去品牌和文案，强调视图、尺寸变量、爆炸图和组件相对视口位置。设计交接和代码审查时，规格图可以成为能回查源码的中间层；仓库也明确要求未知值不编造，适合把 Agent 的视觉产物纳入可核验流程。

应用场景
  • 前端重构前把复杂弹窗的几何约束提炼成可审查规格。
  • 设计系统迭代时制作组件结构说明和短动画演示。
