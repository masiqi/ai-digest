🛠️ Graphicle
一句话

刚在 Show HN 出现的 Rust 代码图谱与项目记忆工具，供编程 Agent 定位符号关系并引用源代码回答问题。

链接

https://github.com/graphicle-ai/graphicle ↗

https://news.ycombinator.com/item?id=50088713 ↗

怎么玩

macOS 上先在测试仓库执行 `brew install graphicle-ai/tap/graphicle`，进入仓库运行 `graphicle setup`；它会建立代码索引和图谱，并列出发现的 Agent 客户端及改动文件。随后用 `graphicle ask "失败请求在哪里重试？"` 看带文件位置的证据片段，再运行 `graphicle graph extract . --code-only` 与 `graphicle graph affected "retry()"` 观察影响范围。注意 setup 可能修改 AGENTS.md 和 Git hooks，先在可回滚仓库试，结束可用 `graphicle disconnect` 撤销。

为什么值得关注

这是一个极早期的 Show HN 项目，官方仓库展示了索引、代码图谱、Agent 对接和带引用检索集中在单个 Rust 程序中的方案。它不是宣称“知道整个仓库”的聊天外壳，而是让问题落到具体文件和行号；仓库尚新、实际大型项目性能和索引质量仍须自己验证。

应用场景
  • 给 Claude Code 或 Codex 找复杂调用链和跨文件影响点。
  • 代码审查时追问某个函数更改会触及哪些模块，并回看源文件。
