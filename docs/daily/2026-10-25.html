🛠️ Voltip
一句话

按住快捷键说话、松开后把识别并可选润色的文字直接输入当前应用的开源语音输入工具。

链接

https://github.com/sunerpy/voltip ↗

怎么玩

打开 GitHub Releases，按自己的 Windows、macOS、Linux 或 Android 系统下载发行包；优先选择安装包而非未经检查就执行远程安装脚本。桌面端首次运行后在设置里授权麦克风和输入权限，选择本地识别模型或自备云端语音服务，先在一个空白文档中按住默认 Ctrl+Alt+Space 说两句，再松开检查识别文本是否落在光标处。需要润色时再配置模型和场景预设，对人名、专业术语建立词典；处理会议、个人资料前确认是否已切换本地模式。

为什么值得关注

项目 README 明确列出按键说话、本地 Qwen3-ASR／SenseVoice／Paraformer、应用场景润色以及长录音导出字幕，不只是一个语音转文字网页。它同时支持云服务和设备侧识别，适合比较隐私、延迟与转写准确率；本地模型仍需下载和设备资源，所谓“本地”只对所选择的识别及润色链路成立。

应用场景
  • 在微信、Obsidian 或 IDE 中口述长段草稿，再按应用自动套用不同润色规则。
  • 把长录音转成文字或 SRT，给访谈和会议制作初稿字幕。
