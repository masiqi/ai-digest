🛠️ Claude Personal Finance：银行账户只读问答，先看权限和地区
一句话

连接自己选择的账户余额与交易记录，查询支出、订阅和账单；美国地区逐步开放的测试版，不是让 Agent 替你管钱。

链接

https://claude.com/resources/articles/introducing-personal-finance-in-claude ↗

https://support.claude.com/en/articles/18185620-use-personal-finance-with-claude ↗

怎么玩

仅适合美国 Pro、Max、Ultra 个人订阅用户，Free、Team、Enterprise 暂不支持，符合条件也未必已开放。侧栏出现 Personal Finance 后，从一个账户开始，经 Plaid 页面自行登录银行并选择共享账户，再问“上个月订阅花了多少”，核对构成数字的交易。不要把银行密码交给聊天窗口，也不要绕过地区限制。本文仅核对官方介绍和帮助文档，没有实际绑定账户。

为什么值得关注

读权限和操作权限被明确分开。Claude 能读银行名称、账户名称与类型、末四位、余额和信用额度，以及最长24个月交易；不能转账、管理或投资资金。投资、贷款等账户只读余额和额度，不等于能读到持仓、交易、利率或合同条款。目前也不能在定时任务、Cowork 或 Claude Code 中调用这些账户。

应用场景
  • 复查重复扣款、订阅和月度现金流，先列出交易，再与银行App或账单核对；余额可能滞后一两天，同一账户重复连接可能重复计数，不能单独据此作投资或借贷决定。
  • Personal Finance hub 内的对话不用于训练，hub 外按个人隐私设置处理。解绑停止读取，不会自动删除旧聊天和 Artifact；共享聊天或 Artifact 可能暴露财务数字，重要财务决定仍应咨询持牌专业人士。

🛠️ OpenAI Images 2.6：把 GIF 与 SVG 输出纳入图像工作流
一句话

新图像模型提供 Flare、Sunburst 两种选择，开发者可直接请求动画 GIF 和静态 SVG；先区分“生成”和“编辑”端点的支持范围。

链接

https://openai.com/index/introducing-images-2-6/ ↗

https://developers.openai.com/api/docs/guides/image-generation#gpt-image-26 ↗

怎么玩

普通用户可在 ChatGPT 或 Codex 先试一个有权使用的角色和简短循环动作，再检查实际导出文件。开发者按文档在 POST /v1/images/generations 中选择 gpt-image-2.6-flare 或 gpt-image-2.6-sunburst，显式指定 output_format 为 gif 或 svg；GIF 可设 frame_count 和 frame_duration_ms，返回的 b64_json 解码后保存对应文件。SVG 要设 n=1。这是文档核验步骤，本文没有调用收费接口或生成样片。

为什么值得关注

GIF 返回的是成品动画，不必把公告里的精灵表示例误当成唯一交付形式；SVG 返回可编辑的静态矢量内容。两种格式都不支持图像编辑端点，也不支持流式输出。complexity 控制规划投入，与 quality 分开；缺省为 high，多元素场景可比较不同档位，而不是一律拉满。官方称整体生成提速50%，这是厂商发布口径，不是本报同机测速，也不承诺角色连续编辑绝不走样。

应用场景
  • 为品牌吉祥物或自有角色做短循环 GIF，逐帧检查肢体、文字、首尾衔接，再放进界面或社交素材。
  • 为网站图标、插画生成 SVG，检查路径、颜色和缩放效果后再交付；不要把静态SVG当作含脚本、外部资源的交互网页，也不要把生成结果当作无须人工审阅的成品。

怎么玩

准备 Android 7.0+ 的备用设备，与电脑接入可信局域网。从仓库 Releases 获取设备端应用，先审查仓库 skill/SKILL.md 再决定是否安装技能；电脑侧 CLI 需要 Node 18+。按 README 依次执行 node skill/bin/aicast discover、node skill/bin/aicast info <dev>，先看设备名、尺寸、触摸/遥控和 WebView 版本；准备不含私密信息的 page.html，再运行 node skill/bin/aicast render <dev> --html-file page.html --wake。最后在屏幕上核对显示与勾选回传，不把 CLI 成功等同于肉眼可用。本文核对README、官网及技能说明，未安装APK或连接实机。

为什么值得关注
