🛠️ DSH Go
一句话

把 DeepSeek Harness 放到 Android 手机上运行，也能连接电脑上的 DSH 会话。

链接

https://github.com/ccch1mneyyy/dsh-go ↗

怎么玩

打开仓库的 Releases/latest，按 Android 设备架构下载 APK，安装前阅读仓库的使用指南与权限说明；首次启动先试本机模式，在内置 Linux 环境里运行一个无敏感数据的小任务，观察过程和中途插话是否能恢复。随后在可信的自家网络环境中依官方指南连接电脑端 DSH，测试同一任务从手机接续。旧测试包签名不同不能直接覆盖，卸载前务必备份手机侧会话与环境；手机操控权限先选最严格的确认档位。

为什么值得关注

它不是给桌面终端加一个网页壳，而是把本机执行与远程电脑连接放在同一 Android 客户端，并有原生对话界面、过程折叠与确认机制。对经常离开电脑又不想中断长任务的人，这是验证移动 Agent 能否真正续行的具体样本；它是第三方社区项目，并非 DeepSeek 官方移动版。

应用场景
  • 通勤时查看长任务进度并补充指令，回到电脑继续处理产物。
  • 在备用 Android 手机上隔离测试低风险 Agent 自动化。

怎么玩

轻量试用先打开模型卡的 Hugging Face Spaces 演示，上传一张没有人脸或敏感信息的单物体照片，旋转查看生成结果，尤其观察看不见的一侧是否凭空补错。要本地运行，先接受模型卡提示的两个门控图像编码器条款并登录 Hugging Face，再 clone github.com/speridlabs/idol-sdk、按 README 安装 Python 3.10+ 与 CUDA 环境，执行 python -m idol.sample --image photo.jpg --mode real；对渲染图改用 --mode synthetic，最后用 3DGS 查看器打开 .ply 核对纹理与轮廓。

为什么值得关注

项目给出了明确的高斯点云输出、显存需求和真实图片/合成图片两类裁剪模式，比只展示“单图变 3D”视频更可复现。模型卡约 7.2GB 峰值显存的数字与秒级演示并不等于任意电脑都能秒出：首次编译、GPU 型号、输入图像及默认采样步数会显著影响耗时，卡片另有分 GPU 实测表可供核对。

应用场景
