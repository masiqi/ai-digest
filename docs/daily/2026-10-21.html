🛠️ DeepInfer
一句话

DeepSeek 开源的高性能推理框架，本次仓库提供 DeepSeek-V4.1-Flash 离线推理与优化内核，不是现成的一键在线 API 服务。

链接

https://github.com/deepseek-ai/DeepInfer ↗

https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017） ↗

怎么玩

先打开仓库 README 的 Getting started，核对硬件门槛：目前支持 NVIDIA SM100 GPU 或华为昇腾 950 NPU，需要 Linux、Python 3.12、GCC 13 及对应 CUDA 13 或 CANN 9.2；不要在普通 Mac 上直接尝试装完整服务。在符合条件的机器上创建空 Python 环境，按 README 选择对应平台从源码构建，再运行 `python examples/offline_inference.py` 做离线样例；模型首次运行会下载，已有权重可按文档设置 `DEEPINFER_HF_MODEL_DIR`。优先检查样例的结构化输出、确定性采样与评估目录，再决定是否适配业务服务。

为什么值得关注

仓库列出 FlashMLA、DeepGEMM、DeepEP 等优化内核及注意力和 MoE 并行、异步调度、受限结构化输出等能力，能让基础设施团队研究生产系统怎样榨取吞吐。不过官方明确说本次不包含完整推理服务所需 KV 缓存系统、分离式服务编排和跨副本负载均衡；社媒传播的收益数字也不应当成普通硬件的可复现收益。

应用场景
  • 有 SM100/昇腾 950 集群的团队，对照现有推理引擎测试批次稳定性和吞吐策略。
  • 研究大模型服务架构的人，阅读离线推理代码与评估脚本，设计自己的实验基线。

🛠️ Pocket TTS
一句话

怎么玩

想先听声音，打开官方体验页输入英文文本、选一条声线后生成试听；想在本机试，在隔离环境按 README 用 `uvx pocket-tts generate` 或安装 `pocket-tts` 后运行 generate，检查生成的 `tts_output.wav`。接着运行 `uvx pocket-tts serve`，在 `http://localhost:8000` 比较几种声音；如需克隆，只上传自己拥有授权的干净 WAV，用 `--voice` 指向该文件。Linux 用户留意 README 的 PyTorch CPU wheel 安装说明以免意外拉取大体积 CUDA 依赖；现有仓库列出的语言未包括中文，别按中文配音工具推荐。

应用场景

  • 用经过授权的声音素材测试角色语音克隆，并记录延迟和品质差异。
